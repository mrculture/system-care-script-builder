About the browser-safe scan

This only reads basic browser-provided hints such as operating system, CPU thread count, memory hint, browser storage estimate, graphics hint, and browser name. It cannot see personal files, installed programs, passwords, documents, or full hardware details.

Why your browser may warn you

Browsers often warn when downloading script files such as PowerShell, batch, or shell scripts because those files can make changes to a computer. That warning is normal and sensible, even when the script was generated locally on this page.

If you feel unsure, you do not have to download it. Use Copy instead, read the code, and create the file yourself. If you copy the script text, this tool can guide you through saving it manually step by step.
